How to Play

Students: Click START, choose a lesson, study the words first, then play Spell It.

Lesson Library: Use search, filters, sorting, favorites, recently played, and preview before playing.

Image-ready folders: Add PNG files like images/weather/lesson-1/sunny.png or images/animals/final-challenge/cat.png. Built-in lesson images use folder paths. Teacher lesson images are saved locally in this browser. If missing, the game uses emoji fallback.

This version uses local teacher lessons only. No admin code. No Firebase.
