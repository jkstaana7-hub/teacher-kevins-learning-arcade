How to Use

1. Prepare the worksheet

Type a title, level, topic, and short instructions. Choose the difficulty and maze size.

2. Generate

Click Generate Maze. The tool creates a new maze and answer path instantly.

3. Save as PDF

Click Download PDF. In your browser print window, choose Save as PDF. The student page and answer key are formatted for A4. The worksheet itself does not include Teacher Kevin branding, website text, or custom footer marks. In Chrome/Edge, turn off “Headers and footers” in the print dialog to remove the browser date, file path, and page number.

4. Extra tools

Use Smart Random for a quick ready-made maze, Reset Settings to return to the default worksheet setup, and Save Maze PNG if you only need the maze image.
